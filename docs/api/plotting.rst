Plotting Package
================

Most users should call plotting methods on a fitted
:class:`jaxsedfit.JAXSEDFit` object, for example
:meth:`jaxsedfit.JAXSEDFit.plot_sed`, :meth:`jaxsedfit.JAXSEDFit.plot_corner`,
and :meth:`jaxsedfit.JAXSEDFit.plot_trace`. The functions below remain
available for standalone use and tests.
